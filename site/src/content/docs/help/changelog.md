## 0.2.1 — 29.10.2026

- **Руководство пользователя** переехало на сайт
  [reestr-docs.up.railway.app](https://reestr-docs.up.railway.app): поиск, справочник по каждому
  экрану и полю, сообщения программы, снимки экранов.
- «Настройки» → «Копии»: подсказка называет настоящие кнопки — «Закрыть файл», затем «Открыть
  файл…».

## 0.2.0 — 28.10.2026

- **Телефон Android**: ввод покупок на ходу, подсказка «Какой картой платить», обмен с
  компьютером через Яндекс Диск.
- **Формулы в суммах**, как в Excel: `=100+250`.
- В колонке «Назначение» — список категорий, который сужается по мере ввода.
- Отметка **«Не в Ср. %»** теперь у регулярного платежа, а не у категории; у «Квартплаты» она
  стоит сама.
- Поиск по таблице `Ctrl+F` — на русском.

## 0.1.0 — 28.10.2026

Первая версия для Windows: файл с паролем, перенос из Excel, лист месяца, кэшбэк по правилам,
кредитки и накопительные счета, сроки, «Свод», экспорт, ежедневные копии, смена пароля,
настройки вида.
