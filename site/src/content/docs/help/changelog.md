## 0.3.1 — 02.11.2026

- Колонка **MCC** снова видна в окне обычной ширины: колонка «Наименование» стала уже.
- Лист «Продукты» у кредитной карты: строка сверки остатка больше не сдвигает «Грейсы»,
  «Погашения» и «Покупки по карте».

## 0.3.0 — 02.11.2026

- **Приложение для телефона и обмен с ним убраны.** Реестр теперь только настольная программа;
  мобильная версия вернётся позже отдельным проектом. Основной файл при открытии обновится сам.
  Копии для телефона и файлы с телефона больше не открываются: откройте основной файл.
- **MCC**: новая колонка в конце журнала и правила кэшбэка по коду. Правило по MCC важнее правила
  по категории. См. [«Правила кэшбэка»](/guide/cashback-rules/).
- **Доступный остаток кредитки**: вносится с датой и сверяется с расчётом «лимит минус долг». См.
  [«Продукты и сроки»](/guide/products-deadlines/).
- **Калькулятор** «кэшбэк или проценты» — кнопка рядом с «Настройками». См.
  [«Калькулятор»](/guide/calculator/).
- «Настройки»: **«Всегда показывать копейки»**.
- Над номерами строк теперь есть заголовок **«№»**.

## 0.2.1 — 29.10.2026

- **Руководство пользователя** переехало на сайт
  [reestr-docs.up.railway.app](https://reestr-docs.up.railway.app): поиск, справочник по каждому
  экрану и полю, сообщения программы, снимки экранов.
- «Настройки» → «Копии»: подсказка называет настоящие кнопки — «Закрыть файл», затем «Открыть
  файл…».

## 0.2.0 — 28.10.2026

- **Телефон Android**: ввод покупок на ходу, подсказка «Какой картой платить», обмен с
  компьютером через Яндекс Диск.
- **Формулы в суммах**, как в Excel: `=100+250`.
- В колонке «Назначение» — список категорий, который сужается по мере ввода.
- Отметка **«Не в Ср. %»** теперь у регулярного платежа, а не у категории; у «Квартплаты» она
  стоит сама.
- Поиск по таблице `Ctrl+F` — на русском.

## 0.1.0 — 28.10.2026

Первая версия для Windows: файл с паролем, перенос из Excel, лист месяца, кэшбэк по правилам,
кредитки и накопительные счета, сроки, «Свод», экспорт, ежедневные копии, смена пароля,
настройки вида.
