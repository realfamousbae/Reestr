Сообщения собраны по местам, где они появляются. Найти нужное быстрее всего поиском: нажмите
`Ctrl+F` в браузере и введите начало сообщения.

## Открытие и создание файла

| Сообщение                                                             | Что делать                                                                             |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Неверный пароль. Проверьте раскладку и Caps Lock.                     | Проверьте язык клавиатуры и Caps Lock. Если пароль меняли, копии открываются старым.   |
| Введите пароль.                                                       | Поле пароля пустое.                                                                    |
| Пароль — не короче 8 символов.                                        | Придумайте пароль длиннее.                                                             |
| Пароли не совпадают.                                                  | Пароль и повтор отличаются — введите оба заново.                                       |
| Отметьте, что пароль записан.                                         | Запишите пароль на бумаге и поставьте галочку.                                         |
| Файл не найден. Возможно, его переместили или флешка отключена.       | Найдите файл кнопкой «Открыть файл…».                                                  |
| Файл с таким именем уже есть…                                         | Программа не перезаписывает файлы — выберите другое имя.                               |
| Это не файл Реестра. / …он не зашифрован.                             | Выбран чужой файл. Выберите файл `.reestr`.                                            |
| Этот файл уже открыт в другом окне Реестра.                           | Закройте второе окно; если его не видно — перезагрузите компьютер.                     |
| Файл создан более новой версией Реестра. Обновите программу.          | [Обновите программу](/start/install/#обновить).                                        |
| Не удалось прочитать или записать файл. Проверьте, что диск доступен. | Проверьте флешку или сетевой диск.                                                     |
| Файл закрыт. Откройте его снова.                                      | Откройте файл на первом экране.                                                        |
| Это рабочий файл телефона, а не основной файл.                        | Откройте основной файл; строки с телефона забираются в нём кнопкой «Забрать».          |
| Это копия для телефона, правки в ней пропадут.                        | Откройте основной файл, из которого она сделана.                                       |
| Не удалось сделать копию файла за сегодня…                            | Папка рядом с файлом недоступна для записи. Работать можно, но копии сегодня не будет. |

## Ввод в таблицы

| Сообщение                                 | Что делать                                               |
| ----------------------------------------- | -------------------------------------------------------- |
| Не удалось распознать дату «…»            | Введите дату как `5`, `5.7` или `05.07.2026`.            |
| Такой даты нет: «…»                       | Проверьте число и месяц (например, 31 апреля не бывает). |
| Не удалось распознать сумму «…»           | Введите число: `1874,50` или формулу `=100+250`.         |
| Процент кэшбэка не может быть больше 100  | Проверьте процент.                                       |
| Название не может быть пустым.            | Введите название.                                        |
| «…» уже есть. Выберите другое название.   | В справочнике уже есть такое название.                   |
| Нельзя удалить: используется в N строках… | Снимите отметку «Активна» вместо удаления.               |
| Порядок — целое число                     | Введите число без дробной части.                         |
| В колонке «Тип» можно: …                  | Введите один из типов карт.                              |
| Строка уже удалена. Экран обновлён.       | Строку удалили раньше; экран показывает актуальное.      |
| Это поле здесь не меняется.               | Колонка считается программой.                            |

## Правила, продукты, поступления

| Сообщение                                                  | Что делать                                                      |
| ---------------------------------------------------------- | --------------------------------------------------------------- |
| Новое правило начните с карты                              | В новой строке правил сначала введите карту.                    |
| У правила должна быть карта                                | Карту правила нельзя очистить.                                  |
| Для этой карты и категории правило в этом месяце уже есть. | Поправьте существующее правило.                                 |
| Лимит не может быть отрицательным.                         | Введите лимит не меньше нуля или оставьте пустым.               |
| Грейс не может закончиться раньше, чем начался.            | Проверьте даты грейса.                                          |
| Сумма должна быть больше нуля.                             | Погашения и поступления вводятся положительной суммой.          |
| Число дней должно быть больше нуля.                        | Проверьте «Грейс обычно, дней» или «Снова открыть через, дней». |
| Грейс «…» не найден: начните с даты его начала             | Введите грейс так, как он подписан: `01.06.26–28.09.26`.        |
| У карты нет ни одного грейса — сначала добавьте его.       | Нажмите «Начался новый грейс».                                  |
| Покупки удаляются в журнале месяца                         | Удалите покупку в журнале её месяца.                            |
| Напишите, о чём напоминание.                               | Заполните «Что сделать».                                        |
| Не удалось определить сегодняшнюю дату.                    | Проверьте дату и время в Windows.                               |

## Импорт и экспорт

| Сообщение                                | Что делать                                                       |
| ---------------------------------------- | ---------------------------------------------------------------- |
| Не удалось прочитать книгу Excel…        | Сохраните книгу в Excel в формате `.xlsx` и попробуйте снова.    |
| В книге нет листа «Служебный»…           | Выбрана другая таблица.                                          |
| В книге нет листов месяцев вида «07.26». | Листы месяцев должны называться `ММ.ГГ`.                         |
| Книгу нужно выбрать заново.              | Выберите книгу ещё раз.                                          |
| Не удалось собрать выгрузку.             | Попробуйте ещё раз; если повторяется — сохраните в другую папку. |

## Отмена

| Сообщение                                                 | Что значит                                                                                                                   |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Отменять нечего. / Возвращать нечего.                     | Больше действий для отмены нет.                                                                                              |
| Журнал изменений повреждён: отменить это действие нельзя. | Отмена этого действия невозможна; данные при этом в порядке. Если нужно вернуть прежнее — откройте [копию](/guide/backups/). |

## Телефон: на компьютере

| Сообщение                                           | Что делать                                                                |
| --------------------------------------------------- | ------------------------------------------------------------------------- |
| Файл с телефона не открывается паролем этого файла… | Введите прежний пароль в поле на надписи или откройте Реестр на телефоне. |
| Файл с телефона сделан из другого файла Реестра.    | На телефоне выберите файлы обмена заново.                                 |
| В папке обмена лежит не файл телефона.              | Проверьте файлы в папке обмена.                                           |
| Файл с телефона сейчас занят…                       | Яндекс Диск его загружает. Попробуйте позже.                              |
| Папка обмена с телефоном не найдена…                | Выберите её снова в «Настройки» → «Телефон».                              |
| Не удалось записать копию для телефона…             | Проверьте, что папка обмена на месте.                                     |
| С телефона нечего забрать.                          | Новых строк нет.                                                          |

## Телефон: на телефоне

| Сообщение                                                      | Что делать                                                                 |
| -------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Сначала выберите файлы обмена на Яндекс Диске.                 | Пройдите первую настройку.                                                 |
| Это не файл с телефона. / Это не копия для телефона.           | Выбран не тот файл: проверьте имена «… — с телефона» и «… — для телефона». |
| Копия для телефона старее той, что уже на телефоне.            | Подождите, пока Яндекс Диск докачает свежую копию.                         |
| Не удалось прочитать копию с компьютера…                       | Проверьте интернет и что Яндекс Диск видит файл.                           |
| Введите и прежний пароль. / Введите новый пароль с компьютера. | Пароль сменили на компьютере — введите оба.                                |
| Это делается на компьютере.                                    | Правила, справочники и «Свод» правятся только на компьютере.               |
| Эта строка уже на компьютере: править её можно там.            | Строку уже забрали — правьте в журнале на компьютере.                      |
| Напишите наименование. / Введите сумму.                        | Заполните поле.                                                            |
