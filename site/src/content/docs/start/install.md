Реестр работает на компьютере с Windows 10 или 11.

## Установить

1. На странице [reestr.up.railway.app](https://reestr.up.railway.app/) нажмите **«Скачать для
   Windows»** — скачается файл `Reestr_<версия>_x64-setup.exe`, например
   `Reestr_0.3.0_x64-setup.exe`. Все версии лежат на странице выпусков проекта на GitHub
   (раздел **Releases**).
2. Запустите его. Windows может показать синее окно **«Система Windows защитила ваш
   компьютер»**. Так бывает с программами без платной цифровой подписи. Нажмите
   **«Подробнее»**, затем **«Выполнить в любом случае»**.
3. Установщик спросит только папку; права администратора не нужны. Ярлык «Reestr» появится в
   меню «Пуск».

Файл `.msi` из того же выпуска — запасной вариант, если `.exe` не запускается.

## Обновить

Скачайте установщик новой версии и запустите его так же. Новая версия ставится поверх старой;
файл с данными остаётся на месте и не меняется установщиком.

Что изменилось в каждой версии — на странице [«Что нового»](/help/changelog/).

:::tip
Если файл создан более новой версией Реестра, старая версия откроет его с сообщением «Файл
создан более новой версией Реестра. Обновите программу.» Обновите программу на этом компьютере.
:::
