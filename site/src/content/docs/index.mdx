## Что умеет программа

<CardGrid>
  <Card title="Лист месяца как в Excel" icon="document">
    Те же колонки, итоги по назначениям сверху, блоки справа, вкладки месяцев внизу. Enter, Tab,
    стрелки, вставка из Excel, `Ctrl+Z`.
  </Card>
  <Card title="Кэшбэк по правилам" icon="star">
    Правила карт на месяц с лимитами: кэшбэк считается сам, а при вводе программа подсказывает,
    какой картой выгоднее платить.
  </Card>
  <Card title="Кредитки, вклады, сроки" icon="warning">
    Грейсы по выпискам банка, долг и даты оплаты, когда снова можно открыть накопительный счёт, свои
    напоминания.
  </Card>
  <Card title="«Свод» за год" icon="list-format">
    Год по месяцам: траты, план дохода, баланс, прирост к прошлому году, кэшбэк. Ничего вводить не
    нужно.
  </Card>
</CardGrid>

Программа **не ходит в интернет**. Данные есть только в вашем файле `.reestr`, и он зашифрован
целиком.
