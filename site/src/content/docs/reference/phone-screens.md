Как настроить и пользоваться — в разделе [«Телефон»](/guide/phone/).

## «Реестр на телефоне» — первая настройка

| Элемент             | Что значит                                                      |
| ------------------- | --------------------------------------------------------------- |
| Копия с компьютера  | Файл «… — для телефона.reestr» на Яндекс Диске. «Выбрать файл». |
| Файл для компьютера | Файл «… — с телефона.reestr» на Яндекс Диске. «Выбрать файл».   |
| «Дальше»            | К вводу пароля; доступна, когда выбраны оба файла.              |

## Вход

| Элемент                       | Что значит                                     |
| ----------------------------- | ---------------------------------------------- |
| Пароль                        | Тот же, что на компьютере.                     |
| «Открыть»                     | Открыть файл.                                  |
| «Выбрать файлы обмена заново» | Вернуться к первой настройке.                  |
| Прежний пароль / Новый пароль | Появляется, если пароль сменили на компьютере. |

Телефон закрывает файл и снова спрашивает пароль, если приложение было свёрнуто дольше 5 минут.

## Главный экран

### Верх

| Элемент   | Что значит                            |
| --------- | ------------------------------------- |
| ‹ ММ.ГГ › | Месяц; стрелки — прошлый и следующий. |
| «Закрыть» | Закрыть файл.                         |

### Новая строка

| Поле         | Что значит                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------------- |
| Наименование | С подсказками «Из прошлых строк». Выбор подсказки заполняет пустые поля из последней такой строки. |
| Сумма, ₽     | Сколько заплатили.                                                                                 |
| Назначение   | Категория.                                                                                         |
| Карта        | Чем платили.                                                                                       |
| Участник     | Кто платил.                                                                                        |
| Дата         | По умолчанию сегодня.                                                                              |
| Регулярная   | Регулярная ли трата.                                                                               |

**«Какой картой платить»** — под назначением: карты с правилом на эту категорию, сколько
кэшбэка выйдет («+X»), процент и остаток лимита. Нажатие выбирает карту.

Кнопки: **«Внести»**; при правке своей строки — **«Сохранить»**, **«Отмена»**, **«Удалить
строку»**.

### Строки месяца

Список «Строки ММ.ГГ» с итогом, новые сверху. Строки с пометкой «ждёт компьютера» — свои, ещё
не забранные компьютером; их можно открыть и поправить. Остальные — только для просмотра.

### Надписи

| Надпись                              | Что значит                                                    |
| ------------------------------------ | ------------------------------------------------------------- |
| «Получена новая копия с компьютера…» | При входе телефон взял свежие правила и справочники.          |
| «Копия с компьютера не прочиталась…» | Работает прошлая копия. Проверьте интернет и Яндекс Диск.     |
| «Не отправлено на Яндекс Диск…»      | Строки сохранены на телефоне; «Отправить», когда будет связь. |
