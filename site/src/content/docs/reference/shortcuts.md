Сочетания работают и в русской, и в английской раскладке.

## Везде

| Клавиши                            | Что делают                   |
| ---------------------------------- | ---------------------------- |
| `Ctrl+Z`                           | Отменить последнее действие. |
| `Ctrl+Y` или `Ctrl+Shift+Z`        | Вернуть отменённое.          |
| `Ctrl+Tab` или `Ctrl+PageDown`     | Следующий лист.              |
| `Ctrl+Shift+Tab` или `Ctrl+PageUp` | Предыдущий лист.             |

Листы перебираются по кругу: месяцы, «Свод», «Продукты», «Сроки», «Справочники».

Пока курсор в текстовом поле (например, «План дохода»), `Ctrl+Z` отменяет набор в этом поле, а
не действие в файле.

## В журнале и таблицах

| Клавиши                         | Что делают                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------ |
| `Ctrl+N`                        | Новая строка журнала.                                                          |
| Стрелки, `Tab`, `Enter`         | Ходить по ячейкам.                                                             |
| Начать печатать, двойной щелчок | Править ячейку.                                                                |
| `Enter`                         | Сохранить правку.                                                              |
| `Esc`                           | Отменить правку.                                                               |
| `Delete`                        | Очистить выделенные ячейки; для выделенных строк — удалить (с подтверждением). |
| `Ctrl+C`, `Ctrl+V`              | Копировать и вставить, в том числе диапазоны из Excel.                         |
| `Ctrl+D`                        | Заполнить вниз значением верхней ячейки выделения.                             |
| `Ctrl+F`                        | Поиск по таблице.                                                              |

## В списках подсказок

В колонках «Наименование», «Назначение», «Участник», «Карта»:

| Клавиши        | Что делают                     |
| -------------- | ------------------------------ |
| `↑` `↓`        | Выбрать в списке.              |
| `Enter`, `Tab` | Принять подсказку.             |
| `Backspace`    | Убрать подсказку наименования. |

## Поля ввода

Поля вроде «План дохода» или полей кредитки: `Enter` сохраняет, `Esc` возвращает прежнее.
