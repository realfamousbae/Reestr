Журнал — таблица трат месяца. Колонки и порядок — как в книге Excel; добавлена только последняя
колонка, «MCC»: в книге её нет.

| Колонка      | Что значит                                                              | Вводится или считается  |
| ------------ | ----------------------------------------------------------------------- | ----------------------- |
| №            | Номер строки; над номерами подпись «№». Щелчок выделяет строку целиком. | считается               |
| Наименование | Что купили или оплатили.                                                | вводится                |
| Назначение   | Категория траты: «Продукты», «Лечение»…                                 | вводится                |
| Регулярная   | Повторяется ли трата каждый месяц.                                      | вводится                |
| Участник     | Кто платил.                                                             | вводится                |
| Дата         | Дата покупки.                                                           | вводится                |
| Сумма        | Сколько заплатили, ₽.                                                   | вводится                |
| %            | Процент кэшбэка.                                                        | вводится или по правилу |
| Кэшбэк       | Сколько кэшбэка, ₽.                                                     | считается или вводится  |
| Карта        | Чем платили.                                                            | вводится                |
| MCC          | Код продавца из банка, 4 цифры. Необязателен.                           | вводится                |

## Наименование

Свободный текст. При вводе программа подсказывает наименование из прошлых записей, как
автозаполнение в Excel: `Enter` или `Tab` принимает подсказку, `Backspace` её убирает.

Когда наименование выбрано из подсказки, пустые колонки строки — назначение, участник, карта,
MCC, «регулярная» — заполняются из последней такой же покупки.

## Назначение

Категория из справочника [«Категории»](/reference/dictionaries/#категории). При вводе
открывается список, который сужается по набранным буквам; стрелки ходят по нему, `Enter` или
`Tab` выбирает.

Можно ввести и новое название: под ним будет написано «Новое назначение — добавится в
справочник». От назначения зависят итоги месяца, «Свод» и то, какое правило кэшбэка применится.

Неактивные категории (без отметки «Активна» в справочнике) в списке не показываются.

## Регулярная

Показывается как «да» или пусто. Принимает:

- **да:** `да`, `д`, `yes`, `y`, `1`, `+`, `x`, `✓`, `v`;
- **нет:** `нет`, `н`, `no`, `n`, `0`, `-`, или пусто.

Сумма регулярных трат — в итогах месяца («Регулярные») и в «Своде».

## Участник

Имя из справочника [«Участники»](/reference/dictionaries/#участники). Достаточно первых букв.
Новое имя добавится в справочник.

## Дата

Показывается как `ДД.ММ.ГГГГ`. Принимает:

| Ввод         | Получится (на листе 07.26)            |
| ------------ | ------------------------------------- |
| `5`          | 05.07.2026 — пятое число этого месяца |
| `5.7`        | 05.07.2026                            |
| `05.07.26`   | 05.07.2026                            |
| `05.07.2026` | 05.07.2026                            |
| `2026-07-05` | 05.07.2026                            |

Разделители — точка, косая черта, дефис или запятая. Пустая ячейка — без даты. Если даты нет в
календаре («31.02»), программа напишет «Такой даты нет».

Дата нужна, чтобы покупка по кредитке попала в нужный [грейс](/guide/products-deadlines/).

## Сумма

В рублях с копейками. Принимает `1234`, `1 234,56`, `1234.5`, `1 200 ₽`, отрицательные (`-50`
— возврат).

Можно ввести **формулу**, как в Excel: `=100+250`, `=(1200-200)/3`. В ячейке останется
результат.

## %

Процент кэшбэка: `6`, `6%`, `1,5`, `0.25 %`. Больше 100 нельзя.

Если ввести процент, кэшбэк посчитается из суммы. Если у карты есть
[правило на месяц](/guide/cashback-rules/), процент подставляется сам и показывается приглушённым
цветом.

## Кэшбэк

Сумма кэшбэка в рублях. Считается из процента или по правилу (приглушённым цветом). Можно ввести
вручную — тогда программа его не пересчитывает, но он расходует лимит правила. Если в одной
вставке заданы и процент, и кэшбэк, главным считается процент.

## Карта

Короткое название карты из справочника [«Карты и счета»](/reference/dictionaries/#карты-и-счета)
— как оно записано в колонке «Как в журнале».

Если включена подсказка карты (галочка «Подсказывать карту при вводе» на экране правил), при
вводе открывается список карт с правилом на назначение строки:

- лучшая карта сверху, с процентом и тем, сколько кэшбэка выйдет или сколько лимита осталось;
- карты с исчерпанным лимитом — внизу, серым, с пометкой «лимит исчерпан»;
- подпись «По правилам месяца и данным журнала».

## MCC

Код категории продавца: банк показывает его в операции. Ровно 4 цифры, ведущие нули важны: `0742`
и `742` — не одно и то же. Пустая ячейка — кода нет. Если ввести что-то другое, программа напишет
«MCC — это 4 цифры» и оставит ячейку прежней.

Код важнее назначения: если у карты строки есть [правило](/guide/cashback-rules/) на этот MCC,
кэшбэк считается по нему. Нет такого правила — по назначению, затем по правилу «на всё».

## Новая строка

Последняя строка таблицы — «Новая строка». Строка сохраняется, как только заполнена первая
ячейка. `Ctrl+N` переходит к ней с любого места.
